# 🎓 CSHUB – دليلك لتخصص علوم الحاسب

## نظرة عامة
**CSHUB** منصة تعليمية موجهة لطلاب تخصص علوم الحاسب، تهدف إلى مساعدة الطالب على فهم التخصص بشكل أعمق، ومعرفة ترابط المقررات الدراسية، وتكوين صورة واضحة لمسار الدراسة من البداية وحتى التخرج.

المنصة تجمع بين العرض الأكاديمي المبسط والتوضيح العملي لدور كل مادة في بناء المهارات الأساسية للتخصص.
