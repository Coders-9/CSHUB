# 🎓 CSHUB – دليلك لتخصص علوم الحاسب

## نظرة عامة
**CSHUB** منصة تعليمية تهدف إلى تقديم محتوى داعم لطلاب علوم الحاسب، يشمل الجوانب الأكاديمية والمهارية المرتبطة بالتخصص، في مكان واحد.

نظرة عامة


### ما يقدمه CSHUB:
- ✅ عرض واضح للخطة الدراسية وتسلسل المقررات
- ✅ توضيح ترابط المواد بدل دراستها كمواد منفصلة
- ✅ شرح دور كل مرحلة دراسية في بناء التخصص
- ✅ خارطة طريق تساعد الطالب يشوف الصورة الكبيرة
- ✅ أدوات ومصادر داعمة للطالب أثناء الدراسة
- ✅ تصميم متجاوب لجميع الأجهزة
- ♿دعم كامل للأوامر الصوتية باللغة العربية لتحسين تجربة المستخدم مصممة خصيصاً لذوي الإعاقة البصرية
