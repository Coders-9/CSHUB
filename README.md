# 🎓 CSHUB – دليلك لتخصص علوم الحاسب

## نظرة عامة
**CSHUB** منصة تعليمية تهدف إلى تقديم محتوى داعم لطلاب علوم الحاسب، يشمل الجوانب الأكاديمية والمهارية المرتبطة بالتخصص، في مكان واحد.



### ما يقدمه CSHUB:
- ✅ تقديم نظرة عامة عن تخصص علوم الحاسب، وطبيعة دراسته
- ✅ عرض منظم للخطة الدراسية للتخصص 
- ✅ خارطة طريق توضّح اهداف المواد ولماذا تتم دراستها 
- ✅ التعرف على بعض الأدوات والمصادر اللي بيقدر الطالب يستفيد منها
- ✅ استعراض بعض من الشهادات المهنية المرتبطة بسوق العمل 
- ✅ تصميم متجاوب يعمل على جميع الأجهزة
- ♿ دعم ميزات وصول (Accessibility) مثل الأوامر الصوتية باللغة العربية لتحسين تجربة الاستخدام، خاصة لذوي الإعاقة البصرية , ( سيتم إضافتها قريبا (: ) 

---
- ## 🛠️ التقنيات المستخدمة

### Frontend
- **HTML5**  
هيكل دلالي متوافق

- **CSS3**  
تصميم متجاوب مع متغيرات CSS

- **JavaScript (ES6+)**  



### Web APIs
- **Speech Synthesis API**  سيتم إضافتها قريبا (:


تُستخدم لتحويل النصوص داخل الموقع إلى صوت باللغة العربية، مما يتيح للطالب الاستماع إلى المحتوى عند التفاعل معه، ويدعم بشكل خاص الطلاب من ذوي الإعاقة البصرية أو من يفضلون التعلّم السمعي.

---
### 🎨 إمكانية الوصول ( سيتم إضافتها قريبا (: ) 
تم تصميم الموقع مع مراعاة مبادئ إمكانية الوصول (Accessibility) وفق إرشادات WCAG 2.1، بهدف تحسين تجربة الاستخدام لجميع المستخدمين، بما في ذلك ذوي الإعاقة البصرية.

🔍 **تقييم المعايير**  
سيتم لاحقًا إن شاء الله إجراء اختبارات شاملة لإمكانية الوصول باستخدام أدوات متخصصة , وسيتم توثيق نتائج التقييم ومستوى التوافق مع معايير WCAG في هذا القسم

---
### الأمان والخصوصية

- 🔒 لا يتم جمع أي معلومات شخصية
- 🔒 لا يتم إرسال أي بيانات إلى خوادم خارجية
- 🔒 الميزات الصوتية تعمل محليًا عبر المتصفح (سيتم إضافتها قريبا (: ) 
- 🔒 الموقع لا يتطلب تسجيل دخول أو إنشاء حساب
- 🔒 لا يتم تخزين أي بيانات حساسة
